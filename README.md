# Hi there, I'm Chandra Mukti Gimnastiyar 👋

**Software Engineer • Game & Interactive Developer (Unity / C# / AR & VR)**

I specialize in building interactive software, 2D/3D games, spatial computing applications, and real-time computer vision systems. As a Software Engineering graduate from Universitas Pendidikan Indonesia and co-founder of **Fantasyx Studio**, I focus on turning complex technical concepts into engaging, intuitive user experiences.

- 🎮 **Current Focus:** Interactive game development, AR/VR simulations, and real-time body/gesture tracking.
- 🛠️ **Core Stack:** Unity Engine, C#, Computer Vision (MediaPipe, OpenCV), and Full-Stack Web Technologies.
- 📍 **Based in:** Bandung, Indonesia
- 🕹️ **Playable Builds:** [itch.io/shinchanstudio](https://shinchanstudio.itch.io) & [itch.io/fantasyx-studio](https://fantasyx-studio.itch.io/)
